EASIEST PHONE METHOD — FIREBASE CONSOLE RULES
1. Open Firebase Console.
2. Open your project.
3. Open Firestore Database.
4. Tap Rules.
5. Copy everything from firestore.rules.
6. Replace the existing rules.
7. Tap Publish.

FOR HOSTING
Firebase Hosting deployment normally uses Firebase CLI.
On a phone, the simplest method is usually:
- upload this ZIP to GitHub
- connect GitHub to Vercel or Netlify
- deploy the site
- then add the deployed domain in:
  Firebase Console > Authentication > Settings > Authorized domains
